# LSPosed Remake (by EzequielDevTeam)

## Introduction 

An updated, modernized version of the **LSPosed Framework**, redesigned with **Material 3** and enhanced for compatibility up to **Android 16**.

> LSPosed is an ART hooking framework delivering consistent APIs with original Xposed, leveraging LSPlant hooking framework. This project is a modernized remake maintained by **EzequielDevTeam**, keeping full credit to the original **LSPosed Contributors**.

## Supported Versions

Android 8.1 ~ 16 (Baklava)

## Modernization Highlights

- 🎨 **Material 3 UI:** Complete overhaul with dynamic colors & modern Material 3 styling.
- 📱 **Android 16 Support:** Updated target and compile SDKs (API 36) with modern native toolchains.
- 🛠️ **Maintained by:** EzequielDevTeam.
